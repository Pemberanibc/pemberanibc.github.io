# Pemberani Tournament Edisi 3.0 — Official Group Draw Film

A 1080×1920, 30 fps draw film rendered frame-by-frame from a sealed, cryptographically committed draw.

```
draw/     pairs.json          the 12 official pairs (exact spelling)
          draw-lib.js         the draw procedure (seed -> allocation)
          generate-draw.js    one-time sealed draw (refuses to run twice)
          verify-draw.js      checks draw.json against the commitment + re-runs it from the seed
          draw.json           THE official draw (seed, 12 selections, groups)
          commitment.json     SHA-256 of draw.json, written and pushed before any frame was rendered
film/     index.html, film.js, timeline.js, fonts/, crest.png   deterministic Canvas-2D film
render/   render.js           headless Chromium -> PNG frames -> FFmpeg (H.264)
          audio.js            original soundtrack + sound design, synthesised from code
          verify-video.js     blind check that the MP4 shows exactly draw.json
out/      pemberani-e3-group-draw.mp4          with soundtrack
          pemberani-e3-group-draw-silent.mp4   same video stream, audio removed
```

## How the draw works

1. `crypto.randomBytes(32)` (the operating system's secure RNG) produces a 256-bit seed.
2. The seed drives an HMAC-SHA256 random stream; integers are taken by rejection sampling, so there is no bias.
3. Twelve times: pick one pair uniformly from the pairs still on the wheel, then pick A or B uniformly.
   Once a group holds six pairs, the remaining pairs go to the other group automatically.
4. The result is written once to `draw.json`; its SHA-256 goes into `commitment.json`.

The film reads `draw.json` and nothing else: the wheel stop positions, the A/B spinner and both group boards are
all computed from that file. Rendering never generates randomness that affects the result.

## Verify it yourself

```bash
sha256sum draw/draw.json            # must equal "sha256" in draw/commitment.json
```

```bash
node draw/verify-draw.js            # hash, reproducibility from the seed, 6 + 6, every pair once
```

```bash
node draw/verify-draw.js --show     # same, and prints the two groups to compare with the video
```

```bash
NODE_PATH=$(npm root -g) node render/verify-video.js draw out/pemberani-e3-group-draw.mp4 out/pemberani-e3-group-draw-silent.mp4
```

The commitment hash was committed to git before the film was rendered, so the git history shows the allocation
could not have been changed afterwards. The first 16 hex characters of the hash are also printed on the final
group board inside the video.

## Re-render

Needs Node 22, Playwright (Chromium) and FFmpeg.

```bash
node render/audio.js draw out/soundtrack.wav
```

```bash
NODE_PATH=$(npm root -g) node render/render.js video draw out/pemberani-e3-group-draw.mp4 out/soundtrack.wav
```

```bash
ffmpeg -i out/pemberani-e3-group-draw.mp4 -an -c:v copy out/pemberani-e3-group-draw-silent.mp4
```
